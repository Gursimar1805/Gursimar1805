# 👋 About Me

I'm a Computer Science (AI/ML) undergraduate who builds and ships full-stack AI applications — not just notebooks. My focus is on turning ML/LLM concepts into deployed, working products.

**🚀 What I've built:**
- **[DataLens AI](https://datalens-ai-y8zs.onrender.com)** — an LLM-powered data intelligence app where users upload CSV/Excel files and get AI-generated insights in real time (FastAPI + SSE streaming + Docker, deployed on Render)
- **[NemoAI](https://github.com/Gursimar1805/NemoAI)** — a full-stack AI chat assistant using NVIDIA Nemotron via OpenRouter, with a FastAPI backend and Streamlit frontend, deployed as separate services
- **AuditLens AI** *(in progress)* — an AI document intelligence tool for audit/compliance review, using Anthropic's Vision API to process audit evidence
- A handful of applied ML projects spanning sentiment analysis, predictive modeling (XGBoost/SVC), and BI dashboards (Power BI, SQL, Excel)

**🔧 Currently working with:** Python · FastAPI · LangChain · Docker · Scikit-learn · XGBoost · SQL · Power BI

**📈 Currently leveling up:** agentic AI architecture (planner loops, tool-calling, memory/state), PyTorch/TensorFlow, and MLOps tooling

**🎓 Background:** B.Tech CS (AI & ML), GTBIT New Delhi (2027) · GenAI & Cloud Intern at BharatCares (AICTE-IBM SkillsBuild) · PwC Advisory Launchpad 2026 alum (SAP track, ranked 1st in college / 74th nationally)
